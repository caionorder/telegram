01 · Aceite
Aprovação de membros

Clicou no link. Não entra. Pede.

O Telegram manda o pedido pro @rh_amanda. O bot dispara duas chamadas, nesta ordem:

1. approveChatJoinRequest(chat, user) 2. sendMessage(particular, texto da Amanda)

API crua equivalente está no README e em examples/comandos.md.

Time faz
  • Nada, se estiver fluido
  • Fila de pendentes: aprova agora e avisa
Time não faz
  • Desligar “Aprovar novos membros”
  • Tornar público / colocar @ / revogar link
  • Usar o link principal (entra direto)
  • Subir segundo bot no mesmo token

Scripts
scripts/rh_amanda.py

Três comandos. Dry-run por padrão.

python3 scripts/rh_amanda.py aprovar --chat -100… --user 111 --nome Joao python3 scripts/rh_amanda.py grupo-texto --chat -100… --texto "Nova vaga…" \ --botao "Ver vaga" --link "https://empregos.exemplo/vaga/atendente" python3 scripts/rh_amanda.py grupo-video --chat -100… --video ./vaga.mp4 \ --titulo "Vaga: Atendente — home office" --botao "Candidatar-se" --link "…"
sem --go

Só imprime o JSON. Não manda nada no Telegram. Use no treino.

com --go

Envia de verdade. Só em grupo de teste, até o responsável mandar.

Regras de ouro
Imprime e cola

Nove linhas. Sem exceção.

  • Pediu → entrou na hora. Fila = alerta vermelho.
  • Só se compartilha o link com pedido (t.me/+).
  • Não mexe em configuração do grupo.
  • Não sobe segundo bot no mesmo token.
  • Não posta no grupo na mão se o automático cobre o horário.
  • Não dispara particular em massa sem ordem.
  • Botão do grupo = Candidatar-se / Ver vaga.
  • --go só em grupo de teste.
  • Viu problema, avisa no mesmo minuto.
