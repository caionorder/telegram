# 01 — Visão geral

Grupo privado **Empregos On-line**. Bot **@rh_amanda_bot** (Amanda, RH). JOINADS, LLC.

## Peças

| Peça | Como é |
|------|--------|
| Grupo | Privado. Não aparece na busca. |
| Aprovar novos membros | Ligado. Sem isso o pedido não chega no bot. |
| Link | Só `t.me/+…` **com pedido**. Não o link “principal” (esse entra direto). |
| Bot | Admin com permissão de convidar e de postar. Um token, uma instância. |

## Funil

```
Anúncio de vaga
  → candidato clica no Telegram
    → pede pra entrar em Empregos On-line
      → @rh_amanda_bot APROVA na hora
      → @rh_amanda_bot manda particular
        → candidato já está no grupo
          → grupo recebe a vaga (texto / vídeo / link)
            → botão Candidatar-se / Ver vaga
```

O grupo não é o produto. É o mural. O clique que vale é o botão da vaga.

## Três máquinas

1. **Aceite** — pedido → aprovação instantânea.
2. **Particular** — Amanda confirma a entrada e pede WhatsApp com DDI.
3. **Grupo** — vaga em texto, vídeo ou link + botão.
