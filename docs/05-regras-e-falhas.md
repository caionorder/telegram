# 05 — Regras e o que fazer se quebrar

## Regras de ouro

1. Pediu → entrou **na hora**. Fila = alerta vermelho.
2. Só se compartilha o link **com pedido** (`t.me/+`).
3. Não mexe em configuração do grupo (privado, aprovar membros, admins, nome).
4. Não sobe segundo bot no mesmo token.
5. Não posta no grupo na mão se o automático está no horário.
6. Não dispara particular em massa sem ordem.
7. Botão do grupo = **Candidatar-se / Ver vaga**.
8. `--go` só em grupo de teste, até o responsável mandar.
9. Viu problema, avisa **no mesmo minuto**.

## Se quebrar

| O que você vê | O que fazer |
|---------------|-------------|
| Gente pendente | Aprova agora + avisa |
| “Pedi e não entrei” | Aprova se estiver na lista; senão a pessoa **cancela e pede de novo** no mesmo link |
| Entrou sem particular | Normal se bloqueou o bot. O que importa é estar no grupo |
| Grupo mudo no horário | Avisa. Não posta na mão |
| Post sem botão | Avisa. Não cola outro link |
| Dois posts iguais | Avisa. Não apaga no feeling |

## Frase

> A pessoa pede pra entrar, o bot aceita na hora, manda o particular, e o grupo trabalha sozinho com vaga + botão. Gente na fila, grupo mudo ou link errado: avisa agora.
